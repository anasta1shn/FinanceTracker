# Finance Tracker 

Finance Tracker — мобильное Android-приложение для учёта личных финансов.
Приложение позволяет добавлять и редактировать доходы и расходы, просматривать статистику, устанавливать месячный бюджет и настраивать валюту и тему интерфейса.

## Возможности

* Добавление доходов и расходов
* Редактирование и удаление транзакций
* Категории операций
* Выбор даты операции
* Поиск по транзакциям
* Фильтрация по типу операции
* Фильтрация по периоду
* Отображение текущего баланса
* Отдельный экран всех транзакций
* Статистика расходов
* Круговая диаграмма расходов по категориям
* График расходов по дням
* Фильтрация статистики по периоду
* Установка месячного бюджета
* Отображение прогресса месячного бюджета
* Выбор валюты: ₽ / $ / €
* Светлая и тёмная тема
* Локальное хранение данных

## Архитектура

В проекте используется архитектурный подход **MVVM**.

```text
UI (Jetpack Compose)
        ↓
    ViewModel
        ↓
   Repository
        ↓
      DAO
        ↓
      Room
        ↓
   Local Database
```

### UI

Интерфейс приложения реализован с помощью Jetpack Compose и Material 3.

Основные экраны:

* Главная
* Транзакции
* Статистика
* Настройки
* Добавление / редактирование транзакции

### ViewModel

ViewModel отвечает за состояние экранов и взаимодействие между UI и данными.

Для наблюдения за изменениями транзакций используется `Flow`.

### Repository

Repository выступает промежуточным слоем между ViewModel и Room DAO.

### Room

Room используется для локального хранения транзакций.

Данные сохраняются на устройстве и доступны после перезапуска приложения.

### SharedPreferences

SharedPreferences используются для хранения пользовательских настроек:

* выбранной валюты;
* месячного бюджета;
* состояния тёмной темы.

## Основные функции

### Главный экран

На главном экране отображаются:

* текущий баланс;
* общая сумма доходов;
* общая сумма расходов;
* последние операции;
* информация о месячном бюджете.

### Транзакции

Пользователь может:

* просматривать все операции;
* искать операции;
* фильтровать доходы и расходы;
* фильтровать операции по периоду;
* редактировать операции;
* удалять операции.

### Статистика

Экран статистики предоставляет визуальное представление финансовых данных.

Используются:

* круговая диаграмма расходов по категориям;
* график расходов по дням;
* фильтр периода;
* общая сумма расходов.

### Настройки

В настройках доступны:

* выбор валюты;
* установка месячного бюджета;
* включение тёмной темы.

## Локальное хранение

Приложение работает без обязательного подключения к серверу.

Транзакции хранятся локально с использованием Room, поэтому пользователь может работать с приложением офлайн.

## Git

Разработка проекта велась с использованием Git.

Основные этапы разработки сохранялись отдельными коммитами, а изменения синхронизировались с GitHub.

## Запуск проекта

1. Клонировать репозиторий.
2. Открыть проект в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить приложение на эмуляторе или Android-устройстве.
